# 📚 책등 책장 앱 — 개발 프롬프트 계획

> 읽은 책을 ISBN(바코드/책 이름)으로 검색해 **책등(spine) 이미지**로 가상 책장에 꽂는 앱.
> 대상 기기: **Galaxy S24+** (Android, 6.7" / 기본 FHD+ 1080×2340, 논리 해상도 약 **412×892dp**)

이 문서는 AI 코딩 도구(Claude Code 등)에 **순서대로 붙여넣을 프롬프트**를 단계별로 정리한 것입니다.
각 단계는 이전 단계가 동작하는 것을 확인한 뒤 진행하세요.

---

## 0. 먼저 정해둔 핵심 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 프레임워크 | **Flutter** (Android 우선) | 카메라·바코드·드래그·커스텀 그리기를 한 코드로 처리, S24+ 성능 충분 |
| 저장소 | **로컬 우선** (Drift/SQLite + 앱 내부 파일 저장) | 로그인 없이 바로 사용, 오프라인 동작. 클라우드 동기화는 나중 단계 |
| 상태관리 | Riverpod | 책장/정렬 상태가 여러 화면에서 공유됨 |
| 바코드 | `mobile_scanner` | EAN-13(ISBN-13) 인식 |
| 책 검색 API | **알라딘 Open API(1순위)** → 카카오 책 검색 → Google Books | 알라딘은 쪽수와 **실물 크기(두께·높이 mm)** 제공 → 책등 두께에 직접 사용 |
| 책등 이미지 | ① 사용자가 업로드한 책등 사진 ② 없으면 **표지에서 자동 생성** | 책등 이미지를 주는 공개 API는 사실상 없음 |

### 책등 이미지 문제 (가장 중요)
공개 API는 **표지**만 주고 **책등**은 주지 않습니다. 그래서:
1. **자동 생성 책등**: 표지의 대표 색 추출 → 그 색 배경에 제목/저자를 세로로 그린 책등을 렌더링 (기본값)
2. **책등 사진 업로드**: 카메라/갤러리 → 세로로 긴 영역 크롭 → 저장 (요구사항의 "이미지 없으면 업로드")
3. 표지 이미지도 없으면 표지 업로드도 가능

### 두께·크기 규칙
- 두께(mm): API 실측값 → 없으면 `쪽수 × 0.06mm` (최소 5mm, 최대 80mm) → 사용자 수정 가능
- 높이(mm): API 실측값 → 없으면 판형 기본값 210mm(A5/신국판 근사)
- 화면 표시: `px = mm × 책장스케일`, 책장 한 칸 너비(mm)를 화면 너비에 맞춰 스케일 계산
- **한 칸의 책 두께 합이 칸 너비를 넘으면 다음 칸(줄)으로 자동 줄바꿈** → 절대 책장 밖으로 넘치지 않음
- 칸 높이보다 큰 책은 칸 높이에 맞게 축소

## 프롬프트 0 — 프로젝트 컨텍스트 (맨 처음 한 번, 또는 CLAUDE.md로 저장)

```
너는 Flutter 앱을 만드는 시니어 개발자야. 앞으로 단계별로 기능을 요청할 거니까 이 컨텍스트를 기억해.

[앱 개요]
읽은 책을 ISBN 바코드 스캔 또는 책 제목 검색으로 찾아서, 실제 책장에 책을 꽂은 것처럼
"책등(spine)" 이미지로 가상 책장에 보여주는 앱.

[대상 기기]
Galaxy S24+ (Android). 세로 모드 고정. 논리 해상도 약 412x892dp, 펀치홀/제스처 바 SafeArea 처리.
다크/라이트 모드 모두 지원. 한국어 UI.

[기술 스택]
- Flutter (최신 stable), Dart null-safety
- 상태관리: Riverpod
- DB: Drift(SQLite), 이미지 파일은 앱 문서 디렉터리에 저장하고 DB엔 경로만 저장
- 바코드: mobile_scanner / 이미지 선택: image_picker / 크롭: image_cropper
- HTTP: dio, 색 추출: palette_generator
- API 키는 --dart-define 로 주입 (코드에 하드코딩 금지)

[데이터 모델]
- Book: id, isbn13, title, author, publisher, pubDate, pageCount,
        thicknessMm, heightMm, widthMm, coverUrl, coverLocalPath,
        spineLocalPath(사용자 업로드), spineColor(자동 추출 색), createdAt
- Shelf(책장 폴더): id, name, shelfWidthMm(기본 800), rowHeightMm(기본 260),
        sortMode(registered | title | custom), createdAt, position
- ShelfItem: id, shelfId, bookId, position(int), addedAt
  → 한 책이 여러 책장에 들어갈 수 있음(버전별 정리 지원)

[코드 규칙]
- 기능별 폴더(features/search, features/shelf, features/book) 구조
- 각 단계 끝에 실행 방법과 확인할 점을 알려줘
- 위젯 테스트/유닛 테스트를 핵심 로직(레이아웃 계산, 정렬)에 작성
```

## 프롬프트 2 — 책 검색 (ISBN / 제목)

```
책 검색 기능을 만들어줘.

[API]
- BookSearchService 인터페이스 + 구현 3개(폴백 순서):
  1) 알라딘 Open API: ItemSearch(제목), ItemLookUp(ISBN13).
     ItemLookUp은 OptResult로 쪽수와 packing(sizeDepth=두께mm, sizeHeight, sizeWidth)을 받아와
  2) 카카오 책 검색 API (Authorization: KakaoAK)
  3) Google Books API
- 결과를 공통 BookSearchResult 모델로 변환
- 두께 계산: API 두께 → 없으면 pageCount*0.06mm (5~80mm 제한) → 둘 다 없으면 20mm
- 높이: API값 → 없으면 210mm

[UI - 검색/추가 탭]
- 상단 검색창(제목 또는 ISBN 입력, 숫자 10/13자리면 ISBN으로 판단)
- 검색창 옆 바코드 버튼 (다음 단계에서 연결)
- 결과 리스트: 표지 썸네일, 제목, 저자, 출판사, 예상 두께
- 항목 탭 → 상세 바텀시트: "어느 책장에 꽂을까요?" 책장 선택(복수 선택 가능) → 저장
- 이미 등록된 ISBN이면 "이미 있는 책" 표시하고 책장만 추가
- 표지 이미지는 저장 시 로컬로 다운로드

로딩/에러/결과없음 상태 처리하고, API 키는 --dart-define 로 받게 해줘.
```

## 프롬프트 4 — 책등 이미지 (자동 생성 + 업로드)

```
책등(spine) 표시 위젯과 이미지 업로드 기능을 만들어줘.

[SpineWidget(book, widthPx, heightPx)]
- spineLocalPath 있으면 → 그 이미지를 BoxFit.cover로 표시
- 없으면 → 자동 생성 책등:
  - 배경: 표지에서 palette_generator로 뽑은 대표색(spineColor, DB에 캐시)
  - 글자색: 배경 명도에 따라 흰/검 자동
  - 제목을 세로로(위→아래, 한글은 글자 세워서, 영문은 90도 회전) 표시, 하단에 저자/출판사 작게
  - 두께가 얇으면(<12px) 제목만, 아주 얇으면 글자 생략
  - 좌우 가장자리에 살짝 그라데이션 그림자 → 실제 책처럼 입체감
- 표지도 없으면 제목 해시로 정한 차분한 색 사용

[이미지 업로드 - 책 상세 화면]
- "책등 사진 등록": 카메라/갤러리 선택 → image_cropper로 세로로 긴 비율 크롭
  (비율 = 두께:높이, 자유 비율도 허용) → 앱 폴더에 저장 → spineLocalPath 업데이트
- "표지 사진 등록": 같은 방식, 표지 없을 때 사용. 등록 후 spineColor 재추출
- "자동 책등으로 되돌리기" 버튼
- 두께(mm)/높이(mm) 직접 수정 슬라이더 + 숫자 입력 (미리보기 실시간 반영)
- 이미지는 최대 높이 1200px로 리사이즈해서 저장(용량 관리)
```

## 프롬프트 5 — 책장 레이아웃 (넘치지 않게)

```
책장 화면의 레이아웃 엔진과 렌더링을 만들어줘. 핵심 로직은 순수 Dart 함수로 분리하고 유닛 테스트 작성.

[레이아웃 계산 - ShelfLayoutEngine]
입력: 정렬된 책 리스트, shelfWidthMm, rowHeightMm, 화면 가용 너비(px)
- scale = (가용너비 - 책장 좌우 프레임) / shelfWidthMm   (px per mm)
- 책 너비px = thicknessMm*scale, 높이px = min(heightMm, rowHeightMm*0.95)*scale
- 왼쪽부터 채우다가 다음 책을 넣으면 칸 너비를 넘을 때 → 다음 줄(칸)로 넘김
- 한 권이 칸 너비보다 두꺼운 극단적 경우 → 칸 너비에 맞게 축소
- 출력: rows[ { items: [ {bookId, x, width, height} ] , usedMm, freeMm } ]
테스트: 넘침 없음, 순서 유지, 빈 리스트, 아주 두꺼운 책, 1000권 성능

[렌더링]
- 나무 질감 책장: 각 칸 아래 선반 판(그림자 포함), 양옆 기둥
- 책은 선반 바닥에 맞춰 아래 정렬(키 다른 책들이 실제처럼 들쭉날쭉)
- 칸 끝의 남은 공간은 비워 둠 (옵션: 마지막 책에 북엔드 장식)
- 세로 스크롤로 여러 칸, ListView.builder로 칸 단위 지연 렌더링
- 책 탭 → 책 상세 / 길게 누르기 → 드래그 시작(다음 단계)
- 상단에 책장 이름, 권수, 칸 수 표시
- 핀치 줌으로 scale 0.7~1.5배 조절(선택)
```

## 프롬프트 6 — 책장 폴더 & 정렬

```
여러 책장(폴더)과 정렬 기능을 만들어줘.

[책장 폴더]
- 책장 탭 상단: 가로 스크롤 칩(또는 드롭다운)으로 책장 전환 + "+" 새 책장
- 새 책장: 이름, 칸 너비(mm), 칸 높이(mm) 설정, "기존 책장 복제" 옵션
  (복제 시 같은 책들/순서를 복사 → 다른 버전으로 정리 가능)
- 책장 이름변경/삭제/순서변경 (삭제 시 확인 다이얼로그, 책 데이터는 유지)
- 책 상세에서 "다른 책장에도 꽂기 / 이 책장에서 빼기"

[정렬]
- 정렬 버튼: 등록순(addedAt) / 이름순(제목, 한글 가나다 → 영문 → 숫자) / 사용자 지정(position)
- 오름/내림 토글
- 선택한 정렬은 Shelf.sortMode로 책장별 저장
- 등록순/이름순 상태에서 드래그하면 → "사용자 지정으로 전환할까요?" 없이
  현재 보이는 순서를 position으로 저장한 뒤 custom으로 자동 전환하고 스낵바로 알림
- "현재 정렬을 사용자 순서로 고정" 메뉴 제공
```

## 프롬프트 7 — 드래그로 순서 변경 & 저장

```
책장 안에서 책을 드래그해 순서를 바꾸고 저장하는 기능을 만들어줘.

- 책 길게 누르기(300ms) → 진동 + 책이 살짝 들려 올라가는 효과(확대+그림자)
- 드래그 중: 손가락 위치 기준으로 삽입 지점 계산(줄/칸을 넘나드는 이동 포함),
  삽입 위치에 세로 인디케이터 표시, 다른 책들은 애니메이션으로 자리 비켜줌
- 화면 위/아래 가장자리로 끌면 자동 스크롤
- 놓으면: 리스트 재배열 → 레이아웃 재계산(넘침 방지 규칙 그대로 적용)
  → 해당 책장의 모든 ShelfItem.position을 트랜잭션으로 한 번에 업데이트
- 드래그 중 화면 하단에 "빼기" 영역 → 놓으면 이 책장에서 제거(실행 취소 스낵바)
- 앱 재시작 후에도 순서 유지되는지 테스트 작성
- 위젯 사이즈가 다른(두께 다른) 아이템이므로 ReorderableListView 대신
  레이아웃 엔진 좌표 기반의 커스텀 드래그로 구현
```
